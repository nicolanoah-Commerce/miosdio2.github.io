# Mios Di-O2 Coming Soon

Static GitHub Pages website for Mios Di-O2, a coming-soon page for a future cycling software application.

## File Overview

- `index.html` — homepage with the coming-soon message and cycling-inspired visual.
- `privacy.html` — privacy policy page.
- `styles.css` — responsive styling, animations, accessibility states and reduced-motion handling.

## Local Folder

Expected local folder:

```text
~/Dev/miosdio2.github.io
```

This project is intended to sit parallel to:

```text
~/Dev/Graph-RAG
```

## Preview Locally

From the project folder, run:

```bash
python3 -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## GitHub Pages Setup

In the GitHub repository, open:

```text
Settings → Pages
Source: Deploy from a branch
Branch: main
Folder: /(root)
```
